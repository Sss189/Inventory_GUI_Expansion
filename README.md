# Inventory GUI Expansion

## 中文

这是一个 Minecraft 1.12.2 模组，加入了整合背包、装备栏、副手栏、玩家模型和 3×3 合成区域的扩展界面，并可通过指令打开合成或烧炼界面。模组还加入了压缩工作台、压缩熔炉、修复锭以及会禁止合成和烧炼的力竭效果。

将项目导入 IntelliJ IDEA，并使用 Java 25 运行 `gradlew build`；构建完成的模组文件位于 `build/libs`。

### 依赖

- 无额外必需依赖

## English

This Minecraft 1.12.2 mod adds an expanded interface that combines the inventory, equipment slots, offhand slot, player model, and a 3×3 crafting grid, with commands for opening the crafting or smelting interface. It also adds the Compressed Crafting Table, Compressed Furnace, Mending Ingot, and a Burnout effect that disables crafting and smelting.

Import the project into IntelliJ IDEA and run `gradlew build` with Java 25; the built mod file will be located in `build/libs`.

### Dependencies

- No additional required dependencies
